# Acknowledgments

Beepster is one small project made possible by a lot of other people's work. Thank you to the
developers, designers, maintainers, documentation writers and testers who share the foundations
we get to build on.

## The projects behind it

- **[Beeper](https://www.beeper.com/) and the Desktop API team:** for the messaging app, local API and documentation that Beepster connects to.
- **[OpenClaw](https://github.com/openclaw/openclaw) contributors:** for the gateway client and scoped approval integration.
- **[Twemoji](https://github.com/jdecked/twemoji), its original creators and current maintainers:** for the emoji artwork adapted into Beepster's watch-sized atlases.
- **[Unicode](https://www.unicode.org/) contributors:** for emoji data and the shared standards behind it.
- **[Pome](https://github.com/GeezusChrotch/pome):** for Organik Apps' shared watch theming groundwork.
- **[Pebble](https://repebble.com/), its original and current teams, and the [Rebble community](https://rebble.io/):** for the watches, SDK, PebbleKit, emulator, tools, documentation and community work that make building for this little screen possible.
- **[Tailscale](https://tailscale.com/):** for the private connection between phone and Mac.
- **Apple's macOS and developer-framework teams:** for the native platform and tools these connectors run on.
- **The open-source toolchain community:** the contributors to [Node.js](https://nodejs.org/), [Python](https://www.python.org/), [Swift](https://www.swift.org/), [Git](https://git-scm.com/) and the build/test tools used throughout these projects.
- **The font designers and maintainers:** the [Inter](https://github.com/rsms/inter), [Roboto](https://github.com/googlefonts/roboto-classic), [Open Sans](https://github.com/googlefonts/opensans), [Montserrat](https://github.com/JulietaUla/Montserrat) and [Poppins](https://github.com/itfoundry/Poppins) project authors, plus [Google Fonts](https://fonts.google.com/) and [FontTools](https://github.com/fonttools/fonttools), for readable type and the tooling to bring it to the watch. Original font notices are retained with the resources.

## Every dependency counts

Our thanks also go to the authors and maintainers of the libraries beneath these direct
dependencies, including the less visible testing, packaging and compatibility work. Dependency
lockfiles and bundled license notices record the components and versions used in each build.

See [third-party notices](THIRD_PARTY_NOTICES.md) for the original artwork and data attribution.
