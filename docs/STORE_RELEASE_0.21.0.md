# Pebble Store update text — 0.21.0

More reliable voice replies, including protection against duplicate dictation
starts and replies going to a different chat. Background updates preserve your
selected conversation and scroll position.
Includes all prior reactions, full-width photos, GIF previews and YouTube thumbnails.

Requires compatible Connector 0.8.7 or newer for normal messaging. Automatic
mark-as-read additionally needs an updated gateway; released Connector 0.8.7 does
not include that new feature. The forthcoming Mac App Store Connector is not yet
available. Pairing, themes, replies and buttons are retained.

The cumulative candidate received positive physical-watch feedback for dictation;
intermittent-crash resolution remains provisional. iMessage message deletion is
still disabled. Please report any recurrence with its approximate time.
