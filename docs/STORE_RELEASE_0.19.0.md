# Pebble Store update text — 0.19.0

Service icons and bitmap emojis are approximately 30% larger, and sender stripes
are twice as wide. Text spacing and line heights accommodate the larger artwork
without overlapping names or clipping messages. Pairing, themes and replies are preserved.

Update Organik Apps Pebble Connector to 0.8.2 or newer, choose Beepster → Set up service,
then reopen phone settings for the larger downloaded emoji replies.
