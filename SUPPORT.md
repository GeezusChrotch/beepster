# Support

Read the [install guide](docs/INSTALL.md), run `./scripts/doctor.sh`, and check the
[troubleshooting guide](docs/TROUBLESHOOTING.md) first.

For reproducible non-security bugs, open a GitHub issue with the Beepster version, Pebble firmware,
phone platform, Beeper Desktop version, messaging service, exact steps, expected result, and actual
result. Redact messages, contacts, account identifiers, tokens, private hostnames, and pairing codes.

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
