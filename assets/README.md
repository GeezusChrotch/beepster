# Beepster artwork

The production mark is `brand/beepster-mark.svg`. Raster derivatives are generated from that flat
SVG so the same silhouette is used in the watch launcher, repository, and Store listing.

The initial concept in `brand/beepster-generated-concept.png` was created with OpenAI's built-in
image generation tool using this prompt:

> Create an original, friendly Beepster symbol: a compact speech bubble subtly shaped like a
> lowercase b, with two tiny signal marks suggesting fast communication. Use a crisp, minimal,
> vector-like style; deep navy #101820 and mint teal #55D6BE; transparent background; strong tiny
> silhouette; no text, gradients, shadows, mockup, device, watermark, or trademarked symbols.

The final SVG was redrawn into flat geometric paths for predictable scaling and 25×25 legibility.
All Beepster-specific artwork in this directory is released under the repository's MIT license.

Current derivatives:

- `brand/beepster-mark-512.png` — repository and general-purpose raster
- `store/beepster-icon-144.png` — Store icon
- `store/beepster-header-1000x320.png` — Store/repository header
- `../resources/images/beepster-menu-icon.png` — 25×25 palettized watch launcher icon
